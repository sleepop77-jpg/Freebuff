# PixelForge

PixelForge is a small pixel-art animation studio designed from the beginning for AI-agent control.

## What it does

- Pixel-perfect canvas editing
- Pencil
- Eraser
- Flood fill
- Color picker
- Custom palette
- Multiple layers
- Multiple animation frames
- Frame duplication
- Frame deletion
- Per-frame duration
- Timeline
- Playback
- Onion skin
- Grid
- Undo / redo
- Local project persistence
- JSON project export
- PNG sprite-sheet export

## Run

npm install
npm start
